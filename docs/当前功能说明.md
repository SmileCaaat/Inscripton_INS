# INS 当前功能说明

更新时间：2026-07-28

本文记录 `main` 分支已经可以实际使用的功能。尚未完成的能力统一记录在 [未完成功能说明](./未完成功能说明.md)。

## 1. 工作区

- 新建本地工作区。
- 在多个工作区之间切换。
- 节点、关系、资源索引、场景和参考板布局自动保存到本机。
- 手动创建本机版本快照。
- 查看、恢复和删除版本快照。

当前工作区数据仍以浏览器本机存储为主，真实项目文件落盘将在 Desktop 版处理。

## 2. Knowledge Node

支持以下基础类型：

- Space 空间
- Person 人物
- Event 事件
- Document 文献
- Artifact 物件
- Media 媒介
- Concept 概念

节点支持标题、副标题、时间、摘要、标签和多资源引用。可以从资源坞拖入已有资源，也可以直接向节点拖入本地文件，文件会自动创建为工作区资源并建立引用。

## 3. Knowledge Graph

- 创建、拖动、框选和多选节点。
- 鼠标滚轮缩放，空白画布平移。
- 从连接点牵线连接已有节点。
- 从悬空连线直接创建空间、人物、事件、文献、物件、媒介或概念节点。
- 删除、复制、撤销、重做和全选。
- `Q` 顶部对齐。
- `C` 为选区创建备注框。
- 节点与空白画布应用内右键菜单。

节点拖动期间只更新画布内部状态，松开后再写回工作区，避免高频布局更新。

## 4. 资源管理

- 拖入单个文件、多个文件或完整目录。
- 按目录、资源类型和关键词筛选。
- 网格与列表两种排列方式。
- 右侧资源预览与基本信息。
- 将资源关联到当前选中的 Node。
- 本机资源 Blob 持久化，刷新后恢复。

资源右键菜单支持：

- 预览资源。
- 关联当前 Node。
- 转到参考板使用。
- 复制、粘贴副本和原地复制。
- 重命名和下载原文件。
- 撤销与重做。
- 删除无引用资源。

有 Node 或参考板引用的资源会禁止直接删除。

## 5. 参考板

参考板用于空间建模参考、文献整理、人物图像比对、纹样拆解及其他研究草稿工作。

已支持：

- 从操作系统拖入文件和目录。
- 直接粘贴剪贴板图片。
- 自动在工作区创建对应资源。
- 从底部资源目录拖入或双击添加已有资源。
- 资源卡片拖动、多选、连线、删除。
- `Q` 顶部对齐与 `C` 备注框。
- 底部资源目录高度调整。
- 右侧资源信息及多格式预览。
- 参考板标题、节点、关系和资源目录高度本机自动保存。

参考板节点和空白画布右键菜单支持：

- 预览、断开连接、下载与图片切图。
- 剪切、复制、粘贴和原地复制。
- 删除、全选、添加备注和自动对齐。

底部资源目录右键支持预览、添加到参考板、下载和图片切图。

## 6. 图片切图

- 宫格分割。
- 拖动横向与纵向分割线。
- 自由画框、移动和调整区域。
- 选择或排除切片。
- 输出 PNG 切片。
- 自动创建切片资源并放入参考板。
- 记录切片来源资源与裁切区域。

当前切片保存在本机 IndexedDB，尚未直接写入用户选择的真实文件夹。

## 7. 三维模型预览

- GLB、GLTF、FBX、OBJ。
- 旋转、平移和滚轮缩放。
- 自动取景与正视图。
- 网格显示开关。
- 内嵌动画播放、暂停和动画片段选择。

建议当前优先使用资源依赖完整的 GLB 文件。外部纹理与压缩模型边界见未完成功能说明。

## 8. 文献与媒体预览

- PDF.js：PDF 分页与缩放。
- Mammoth.js：DOCX。
- SheetJS：常见 Excel、ODS、CSV、TSV。
- epub.js：EPUB。
- wavesurfer.js：音频波形与播放。
- 常见文本源码。
- 图片和视频。

## 9. 应用级右键

浏览器原生右键菜单已在 INS 中全局禁用。

图谱、资源和参考板使用自己的上下文菜单。右键对象时会先选择对象，菜单操作针对当前对象或当前多选集合；右键画布空白处时，粘贴位置以右键坐标为锚点。

## 10. 当前禁用入口

- Narrative
- 专题

两个入口保留在界面中但保持灰置，避免把尚未完成的原型误认为可交付功能。
