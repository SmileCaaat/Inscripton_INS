# INS 未完成功能说明

更新时间：2026-07-28

本文只记录当前版本中尚未完成、无法在不扩大系统边界的情况下直接补齐的能力。界面中对应的未完成入口应保持禁用或明确提示，不得伪装为已经可用。

已完成能力请查看 [当前功能说明](./当前功能说明.md)，Electron 路线请查看 [Desktop 桌面版规划](./Desktop桌面版规划.md)。

## 1. 云盘多人协作

当前状态：未完成。

目前工作区结构、节点数据和参考板布局保存在浏览器本机存储中，资源原文件保存在本机 IndexedDB。界面已经不再显示虚假的“云盘同步正常”状态。

待完成内容：

- 选择并确认云盘协作方式，例如同步整个 INS 工作区目录，或使用 OneDrive、坚果云、Dropbox 等同步盘。
- 将工作区数据迁移为可落盘的项目文件，而不是只保存在浏览器存储中。
- 处理两台设备同时修改同一节点或参考板时的冲突。
- 提供外部修改检测、冲突副本和手动合并记录。

## 2. 多参考板管理

当前状态：未完成。

目前每个工作区只有一个参考板数据槽，支持改名、资源放置、连接、对齐、备注框和本机自动保存。

待完成内容：

- 新建、复制、重命名和删除多个参考板。
- 参考板列表、封面和最近修改时间。
- Node、专题与参考板之间的多重引用。
- 跨参考板复制对象和链接跳转。

## 3. Narrative 自由编排

当前状态：部分完成。

目前已有新增场景、切换场景、编辑场景眉题、标题和说明，以及进入 Explorer 预览的原型。由于完整编排能力尚未完成，Studio 顶部的 Narrative 入口现阶段保持禁用；文字块、节点卡片、资源卡片和三维场景工具同样保持禁用。

待完成内容：

- 场景元素的数据模型，包括文字、Node、资源、3D 视图、热点和链接。
- 元素拖放、缩放、旋转、层级、对齐和组合。
- 场景过渡、时间轴、动画与交互触发器。
- 在 Narrative 中保存三维相机位置、模型状态和节点热点。

## 4. 专题内容编选

当前状态：部分完成。

目前已有创建专题并进入 Explorer 的原型，但专题仍使用工作区现有场景，尚不能独立选择节点、资源和 Narrative。为避免误用，Studio 顶部和侧栏中的专题入口现阶段保持禁用。

待完成内容：

- 专题节点与资源的选择器。
- 专题自己的 Narrative 绑定和场景顺序。
- 专题封面、视觉主题和展示权限。
- 专题引用数量随实际编选内容实时计算。

## 5. 三维模型格式边界

当前状态：基础预览已完成。

已支持：

- GLB、GLTF、FBX、OBJ 模型读取。
- 轨道旋转、平移、滚轮缩放、自动取景、正视图、网格开关。
- 双面材质、基础灯光、阴影和内嵌动画播放。
- 多动画模型的动画片段切换。
- 模型原文件保存在本机 IndexedDB，刷新后可恢复预览。

尚有限制：

- 独立 `.gltf` 引用的外部 `.bin` 和纹理文件尚未建立目录级资源解析；建议当前优先使用 GLB。
- OBJ 对应的 MTL 与外部纹理目录尚未自动配对。
- FBX 外部纹理、DRACO、KTX2、Meshopt 等压缩资源尚未接入专用解码器。
- 尚未提供材质通道调节、骨骼显示、测量、剖切和标注。
- 超大模型尚未建立分片、LOD、渐进加载和显存保护策略。

## 6. 文献与媒体预览的剩余边界

当前状态：常用格式预览已完成。

已支持：

- PDF.js：PDF 分页、上一页/下一页和缩放。
- Mammoth.js：DOCX 排版转换和隔离预览。
- SheetJS：XLSX、XLS、XLSM、XLSB、ODS、CSV、TSV，并支持工作表切换。
- epub.js：EPUB 分页阅读、字号调整和前后翻页。
- wavesurfer.js：MP3、WAV、OGG、M4A、AAC、FLAC、OPUS 波形与播放控制。
- TXT、Markdown、JSON、XML、HTML、CSS、JavaScript、TypeScript 纯文本预览。
- 图片和视频本机预览。

尚未完成的低频格式：

- 旧版二进制 Word `.doc`，Mammoth.js 只处理 DOCX。
- PowerPoint、Keynote、Pages 等演示或排版工程文件。
- 受密码保护或加密的 PDF、Office、EPUB 文件。
- 扫描 PDF 的 OCR 文本识别和全文检索。

## 7. 扫描 PDF OCR 队列

当前状态：待完成。

图片 OCR 已可在资源工作流中使用；PDF 的视觉预览已经由 PDF.js 提供，但尚未接入逐页 OCR 队列。

后续实现必须坚持单页渲染、单页保存、释放 Canvas/Blob/ImageBitmap、暂停/继续/取消和单页失败重试，不能一次性将整份扫描 PDF 展开到内存。

## 8. 图片切图的文件系统输出

当前状态：部分完成。

切片已经能生成 PNG 资源、写入本机 IndexedDB、放入参考板并记录来源区域，但并未直接写入用户硬盘上的真实文件夹。

待完成内容：

- 通过桌面壳或 File System Access API 选择真实输出目录。
- 保持目录授权并支持覆盖、重命名和批量导出。
- 多边形区域、遮罩切图、区域模板和再次编辑。

## 9. 完整关系与备注编辑器

当前状态：部分完成。

图谱可以牵线创建关系，也可以创建 Q 对齐和 C 备注框。

待完成内容：

- 编辑关系类型、方向、证据、置信度和时间范围。
- 编辑备注框标题、颜色和说明。
- 移动备注框时可选择是否同时移动框内对象。
- 参考板关系线的类型、颜色、箭头和说明编辑。

## 9. Desktop 桌面运行环境

当前状态：规划完成，尚未实施。

浏览器版目前使用 IndexedDB 和 localStorage 保存本机数据，尚未提供 Electron 主进程、Preload、安全文件系统接口和安装包。

待完成内容：

- Electron Main、Preload 与 Renderer 构建链。
- Windows 安装包、便携测试包和应用图标。
- 真实工作区目录与项目文件。
- 原生文件选择、资源管理器定位和外部文件变化检测。
- 浏览器版与 Desktop 版共用数据模型，同时保持独立构建。
